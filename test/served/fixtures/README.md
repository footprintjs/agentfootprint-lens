# Served-tab fixtures

Twelve frozen runs — eleven agentfootprint 9.94.0 charts and one plain
footprintjs 9.23.1 chart — `{ snapshot, events, structure }` as `recordRun`
froze them (the chart's `events` is `[]`), generated by `generate.ts`, never
hand-authored. Since 9.90.0 the agent charts DECLARE their milestones as tags
(`CommitBundle.tags` / `structure.tags`), which is what the tag legend and the
picker read. Regenerating on 9.94.0 (0.52.0) added exactly one key path to
every agent fixture — `receipt.cache.strategy` (`'*'`) — beside runIds, hashes
and timestamps; `llmcall.json` gained a whole receipt (agentfootprint 9.91.0
made `LLMCall` mint), so the receipt-less arm moved to `no-receipt.json`.
Regenerate all with `npx tsx test/served/fixtures/generate.ts`; regenerate one
with `npx tsx test/served/fixtures/generate.ts <name>` (the other files are not
touched — every run mints a fresh runId, so a regenerated fixture never has the
bytes it had).

| file | shape | what it exercises on the tab |
|---|---|---|
| `flat-dynamic-tools.json` | Agent · `reactMode: 'dynamic'` · two tools · call → done | two epochs; every hashed row **Verified** — system, pieces, messages and both tool schemas; `temperature: 0.25` on the receipt |
| `dynamic-grouped.json` | the same turn · `'dynamic-grouped'` | the epoch's pieces live in the turn's inner log; the mount stop IS the epoch |
| `llmcall.json` | `LLMCall` chart | mints a receipt (9.91.0) with `cache.strategy: null` (9.93.0) → rows **Verified**, the strategy line reads *no cache strategy*, `provider-defaults` is the only gap — the `cache-transform` card is NOT drawn; `omittedForAttention` absent on a 9.93+ receipt → count 0 |
| `no-receipt.json` | the same chart, `recordReceipt: false` | mints none → `no-receipt-on-chart` with `cause: 'no-receipt-committed'`; `cache-transform` still raised (no receipt can say); every row **Reconstructed**; **Not on record** for receipt-only fields and for the attention drops |
| `paused-resumed-no-base.json` | pause + resume, then `initialState` DELETED | `no-fold-base`; the resumed leg is epoch 2 with no epoch 1 in this recording; the system row disagrees and stays **Reconstructed** (the gap excuses a short aggregate), the one rebuilt message pairs with its receipt row by key and is **Verified**; receipt-only counts |
| `tool-forced.json` | `outputSchema(…, { strategy: 'tool-forced' })` | the forced tool named and marked; its schema row absent; `forced-tool-schema` gap |

The system text is the SAME at both epochs (the step note leads the tool's description, not the prompt) — SINCE PREVIOUS reads **unchanged** for it |
| `hidden-skills.json` | `PermissionPolicy` role `support` may not see `payroll` | `hiddenSkillIds: ['payroll']` on the FOLD at every stop from the first call; nowhere on any receipt |
| `instructions-move.json` | one tool, `lookup`, and two `defineInstruction`s: `before-lookup` (active until a tool has run) and `after-lookup` (on `lookup`'s return) | the SYSTEM TEXT differs between epochs — epoch 1 is `support bot` + `Look the order up before you answer.`, epoch 2 is `support bot` + `The order is on record. | `tagged-chart.json` | a plain footprintjs chart: `seed → call-llm[milestone:llm-turn] → normalise → route[milestone:decision, audit] → finish[audit]`, no agent events | the TAG LEGEND on a name the domain does not classify: `audit` prints its raw name beside the milestone labels, declared in the structure and hit twice; `tagStops(['audit'])` keeps `route` and `finish` and folds `normalise` into the turn before it |
| `window-evicts.json` | `.window(slidingWindow({ keepRecentTurns: 1 }))`, one tool, three calls | epoch 3's receipt carries `omittedForAttention: { count: 2, hashes }` — the assistant tool call and its result that left at iteration 3's head — and both hashes are epoch 2's `messages.entries[].hash` (epoch 1 served only the user turn): two withheld message edges, *last served on epoch 2*. Epochs 1 and 2: `none-on-receipt` → count 0, nothing withheld. The generator checks the pairing on the real run |
| `wrap-up.json` | `maxIterations: 2`, a model that always calls a tool | epoch 3 is the wrap-up call: `tools.withheld: 'wrap-up'` on the receipt and the view, rendered verbatim; no tool row and no count of the tab's own |

The one edit ever made to a recording is the deleted `initialState` in
`paused-resumed-no-base.json`, and the generator says so at the line it does it.
