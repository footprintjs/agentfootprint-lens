# Served-tab fixtures

Eight frozen agentfootprint 9.88.0 runs, `{ snapshot, events, structure }` as
`recordRun` froze them — generated by `generate.ts`, never hand-authored.
Regenerate all with `npx tsx test/served/fixtures/generate.ts`; regenerate one
with `npx tsx test/served/fixtures/generate.ts <name>` (the other files are not
touched — every run mints a fresh runId, so a regenerated fixture never has the
bytes it had).
