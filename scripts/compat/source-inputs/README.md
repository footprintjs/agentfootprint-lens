# Lens compatibility inputs

The stable source and packed consumer gates read the committed registry
cohort. The compatibility inputs here serve two distinct jobs.

- `renderer.mjs`, `transport.mjs` and `archives.mjs` admit the reviewed
  original UI renderer archive. Its fixed run and tested parents, complete
  job set, original package and manifest must agree. The bounded archive
  reader treats the generated audit lock as evidence. The original
  thirteen-member artifact and twenty-member tarball are read as data.
- `materialize.mjs` and `gates.mjs` run the independently installed
  historical published commentary CONTROL. Its own temporary strict
  lock pins AgentFootprint 14.7.2, FootPrint 12.3.0, Foottrace 1.11.1 and
  Explainable UI 1.0.1. Its checked-out source inventory, resolved lock
  and installed versions are checked before and after each gate.

The CLI is hosted-only. Adjacent tests check the renderer admission and
control's source inventory without installing packages.
