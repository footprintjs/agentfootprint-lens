# Recorded time projections

These units print the producer's recorded time facts and declared input fields.
`awaitingInput.ts` locates the supported pause homes and retains the original
request identity; both time-field display and the native-reader host port use
it. It interprets no reserved binding metadata or time text. Existing time
behavior tests live under test/time; host-reader tests sit beside that code.

`askMetadata.ts` snapshots only known display data, using dense ordinary
own-data arrays, at most128fields and256choices/labels per field, with a
shared4MiB UTF-8 string/key budget per metadata read. Accessors, sparse/method-
overridden arrays and failed reads produce a named unavailable result; no
private exception text or truncated choice is shown. Opaque binding context
is never decoded here. The original request still reaches the native reader.
