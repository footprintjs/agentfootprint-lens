# Time reply host port

The injected reader is the producer's public `timeReplyPairs`, supplied by a
host using agentfootprint/time14.4 or later. Lens does not statically import an
API absent from its older peer floor, read reserved context, or derive sibling
IDs. `read.ts` hands the original full request to that reader and projects
consumer-safe field metadata. Missing reader, no pairs and reader refusal are
separate outcomes. Only a completely covered form can be submitted by the
simple fallback; registered collectors keep ownership of all their fields.
