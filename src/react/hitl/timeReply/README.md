# Time correction controls

Controlled native range/correction inputs expose exact field-keyed values to
the owning collector. The simple fallback owns submission only for a complete
form. Registered collectors retain their own full decision and wire POST;
Lens never classifies time words, converts zones or invents native cancellation.

A request generation includes safe display metadata, native pair projection,
opaque context revision identity, session and collector identity. Refused/repeat
or field revisions reset controls even when requestId is unchanged. The local
comparison is never a DOM key or a chart argument; only a numeric revision is
used as a component key. Retained callbacks from old generations do nothing.
Keep native context immutable and provide its new revision from the host.

The fallback records a local structured decision only after the host callback
returns. On rejection the remote outcome is unknown: controls stay blocked
until the host supplies the current question. No automatic retry or invented
cancellation decision is added. Registered collectors keep their complete
submit and receive optional metadata for controlled field reuse.
